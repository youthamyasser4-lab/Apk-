# مصاريفنا Offline Android

ده مشروع Capacitor مبني على **النسخة القديمة الشغالة** من `index.html` اللي اتبعتت في المحادثة، مش نسخة الـ Glass UI الجديدة اللي كان فيها زر الحفظ مش بيستجيب.

## اللي اتضاف
- كاش محلي للحسابات والمعاملات بعد أول تسجيل دخول ناجح.
- حفظ المعاملة محليًا قبل محاولة رفعها، مع قائمة انتظار للمزامنة عند رجوع الإنترنت.
- مزامنة تلقائية عند رجوع الاتصال، ومعرّف ثابت لكل معاملة لتقليل التكرار.
- تنبيه أعلى الشاشة يوضح حالة الاتصال وعدد المعاملات المنتظرة.

## متطلبات بناء APK
- Node.js LTS و npm.
- Android Studio مع Android SDK.
- اتصال إنترنت على الكمبيوتر لتنزيل حزم npm أول مرة.

## الخطوات على الكمبيوتر
1. فك ضغط الملف.
2. افتح Terminal داخل المجلد.
3. نفّذ: `npm install`
4. نفّذ: `npm run android:init` (مرة واحدة فقط).
5. افتح المشروع في Android Studio: `npm run android:open`.
6. من Android Studio اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
7. بعد أي تعديل في ملفات الويب، نفّذ `npm run android:sync` ثم ابنِ APK مرة أخرى.

## مهم قبل الاعتماد عليه
- أول تسجيل دخول وتنزيل البيانات يحتاجان إنترنت. بعد ذلك يقدر التطبيق عرض البيانات المخزنة وإضافة معاملات دون اتصال.
- هذا الإصدار يخزن الكاش وقائمة الانتظار في مساحة التطبيق المحلية (localStorage داخل WebView)، وليس قاعدة SQLite أصلية حتى الآن.
- عمليات إضافة المعاملات هي المسار المدعوم دون إنترنت. إنشاء الحسابات، الدعوات، قبول الدعوات، والحذف/تعديل بيانات الحساب تتطلب اتصالًا.
- المزامنة تعتمد على أن جدول `transactions.id` يقبل UUID يحدده العميل، وعلى سياسات RLS الحالية في Supabase. اختبرها على حساب تجريبي قبل تسجيل معاملات مهمة. لا تستخدم مفتاح service-role داخل التطبيق.
- الكاش المحلي ليس نسخة احتياطية. لا تمسح بيانات التطبيق قبل مزامنة قائمة الانتظار.
